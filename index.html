Telefon & Bilgisayar Web Uygulaması Kurulumu ve Eşitleme

Ana Ekrana Uygulama Olarak Yükle (PWA)

Telefonunuzda ve bilgisayarınızda adres çubuğu olmadan tam ekran uygulama gibi açılır.

1. Telefon ve Bilgisayar Arasında Otomatik Canlı Eşitleme

santiye-stok Firebase projeniz varsayılan olarak tanımlıdır. Diğer cihazınıza Cihaz Eşleştirme Kodunu yapıştırarak aynı veritabanına bağlayabilirsiniz:

Firebase (Firestore) Bağlantısı, Gemini OCR & Veri Yedekleme

1. Anlık Veri Yedekleme & Geri Yükleme (JSON / Excel)

Tüm zimmet, şantiye malzemeleri, transferler ve fatura fotoğraflarınızı tek dosya olarak bilgisayarınıza/telefonunuza yedekleyebilir veya başka bir cihaza aktarabilirsiniz.

2. Firebase Cloud Firestore Bağlantısı (santiye-stok)

Firebase Console'daki santiye-stok projenizin Project ID ve Web API Key bilgileri gömülüdür. Verileriniz santiye_uygulama/ana_veri belgesine senkronize edilir.

3. Gelişmiş Yapay Zeka Çoklu Satır Fatura Okuma (İsteğe Bağlı Gemini API Key)

Uygulama varsayılan olarak tarayıcı içi OCR (Tesseract.js) ile faturaları ücretsiz tarar. İsterseniz AI Studio API anahtarınızı girerek çok kalemli fatura tablolarını Gemini Flash ile satır satır otomatik okutabilirsiniz.
